# walmart-sales-sql-project
Interactive SQL analytics project exploring Walmart sales trends, department performance, holiday impact, and executive KPIs using MySQL.
# Walmart Sales SQL Project

## Project Overview

This project analyzes Walmart sales data using MySQL.

The goal of the project is to answer business questions about:

- Store performance
- Department performance
- Holiday sales
- Weather impact
- Executive KPIs

---

## Dataset

Source:
- Walmart Store Sales Forecasting Dataset (Kaggle)

Tables used:

- Sales
- Features
- Stores
